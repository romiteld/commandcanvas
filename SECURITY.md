# Security Policy

## Supported versions

Security fixes are considered for the current `main` branch and the current
public deployment. Historical commits and local forks are not supported.

## Report a vulnerability responsibly

Use this repository's private GitHub vulnerability-reporting channel. Do not
open a public issue, pull request, discussion, or social post with exploit
details. Include a concise reproduction, affected route or component, impact,
and any safe remediation notes. We will acknowledge the report, assess it, and
coordinate disclosure after a fix is available.

## Scope and privacy

This policy covers the CommandCanvas application source, first-party API
routes, and database migrations in this repository. Third-party services and
separately licensed private relay software are outside this repository's
source boundary; see [SOURCE.md](SOURCE.md).

Never include API keys, access tokens, passwords, invitation links, personal
email addresses, camera footage, meeting content, or other private data in a
report. Redact evidence to the minimum needed to reproduce the issue. Reports
and submitted evidence are used only to investigate and remediate the security
issue.
