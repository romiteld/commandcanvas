# One-click judge instructions

Open **<https://commandcanvas.vercel.app/demo>**. No signup, login form, password, third-party account, API key, or configuration is required. The page creates an anonymous authenticated browser identity behind the scenes and opens a ready room with three semantic objects.

Try the core path:

1. Click **Sketch**, draw two or three boxes with arrows, then click **Done**.
2. Select **Rough architecture** and click **Make usable**. The original sketch remains while a structured diagram appears beside it. If live model access is unavailable, the page reports the failure without replacing the source or fabricating a result.
3. Move or resize the result. Pin, minimize, restore, trash, and undo all have visible non-gesture controls.
4. Click **Prepare meeting packet**. Review the exact object snapshot and demo recipient, then click **Approve packet**.
5. Click **Request email send**. Nothing is sent until you press **SEND** in the explicit confirmation. The public environment may intentionally return **Preview only: not sent** when Resend or the recipient allowlist is not configured.
6. Use **Reset demo** at any time to remove the current demo room and create a clean fixture room.

For realtime collaboration, click **Copy invite**, open the capability link in a second private/incognito browser window, and move the second participant’s cursor or create a note. Both windows should show actual Supabase Presence and the same durable revision.

For WebMCP, open the same `/demo` URL in a supported Site Tools host. Ask: **“What is on this canvas?”**, then **“Create a note titled Judge feedback saying The spatial object model is clear.”** The page should show the registered tool status and an attributable WebMCP receipt. In an ordinary browser without WebMCP, the status honestly reads **Site Tools unavailable** and all essential pointer controls remain functional.
