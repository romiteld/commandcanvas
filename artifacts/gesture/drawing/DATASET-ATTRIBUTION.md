# Drawing trajectory dataset attribution

The tuning evaluation in this directory uses the **In-Air Hand-Drawn Number and Shape Dataset** by Basheer Alwaely and Charith Abhayaratne, University of Sheffield.

- Source: <https://orda.shef.ac.uk/articles/dataset/In-Air_Hand-Drawn_Number_and_Shape_Dataset/7381472>
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Archive SHA-256: `321c0f53ce2f1f33aa821a36df3ed29261d11934dc945d47a9d3abf79daf4c1e`
- Archive contents: 5,000 number trajectories and 5,000 shape trajectories stored as raw X/Y/Z coordinate samples without normalization or smoothing.

Requested citation:

> Basheer Alwaely and Charith Abhayaratne. “Graph Spectral Domain Feature Learning With Application to in-Air Hand-Drawn Number and Shape Recognition.” *IEEE Access*, vol. 7, 2019, pp. 159661–159673.

The source archive is not redistributed in this repository. The JSON artifact contains aggregate filter-evaluation metrics and configuration only.
